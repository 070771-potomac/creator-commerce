Phosphor icon (the repo's iconLibrary, regular weight) rendered via CSS mask so it inherits currentColor; use for every glyph. Older Lucide names are mapped automatically.
```jsx
<Icon name="package" />
<Icon name="download-simple" size={14} color="var(--muted-foreground)" />
```
Sizes: 12 (xs buttons, badges), 14 (sm), 16 (default).

Action button from shadcn base-nova (32px default, 7.2px radius, green primary); use one `default` per view for the main action.
```jsx
<Button icon="plus">New product</Button>
<Button variant="outline" size="sm">Duplicate</Button>
<Button variant="ghost" size="icon" icon="more-horizontal" />
```
Variants: default (primary green), outline, secondary, ghost, destructive (tinted red, not solid), link. Sizes xs/sm/default/lg + icon, icon-sm, icon-lg. Press = 1px translate down.
